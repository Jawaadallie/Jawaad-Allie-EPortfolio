  <h2>Reflection on Coding in Markdown (STAR Method)</h2>
  <ul>
    <li><strong>Situation:</strong> Developing this digital portfolio required us to build structured web documentation without using traditional visual editors, strictly relying on Markdown formatting.</li>
    <li><strong>Task:</strong> I needed to code and format my Curriculum Vitae and overall digital portfolio layout cleanly using GitHub Flavored Markdown (GFM).</li>
    <li><strong>Action:</strong> I learned and applied various Markdown syntax rules, including headers, nested lists, bold formatting for emphasis, and structured tables to properly organize my skills, education, and experiences.</li>
    <li><strong>Result:</strong> I successfully authored source files that are clean, developer-friendly, and render beautifully aligned on the web, significantly strengthening my technical documentation skills.</li>
  </ul>
</div>

<div class="glass-card">
  <h2>Reflection on the Use of GitHub Pages (STAR Method)</h2>
  <ul>
    <li><strong>Situation:</strong> To complete the assignment and make my portfolio accessible to employers, my locally coded Markdown portfolio needed to be deployed to the live internet.</li>
    <li><strong>Task:</strong> I was tasked with hosting the project files online using GitHub Pages to create a premium, publicly viewable digital footprint.</li>
    <li><strong>Action:</strong> I set up a Git repository, committed all my generated Markdown documents and custom CSS configuration, and pushed my project to GitHub. I then successfully enabled GitHub Pages from the repository settings.</li>
    <li><strong>Result:</strong> My portfolio is now actively hosted and reachable via a public URL, proving my competence with version control and demonstrating my ability to independently deploy and manage web assets.</li>
  </ul>
</div>
